# Bank Management System

## 📌 Project Overview

The Bank Management System is a Python-based mini project developed to perform basic banking operations. It provides a simple way to manage customer account information and perform banking transactions.

## 🎯 Objectives

- Manage bank customer accounts
- Store customer information
- Perform basic banking operations
- Store and retrieve data using files/database
- Understand Python programming and database concepts

## 🛠️ Technologies Used

- Python
- SQLite
- CSV
- File Handling

## ✨ Features

- Create bank account
- View account details
- Search account
- Deposit money
- Withdraw money
- Manage customer information
- Store data using CSV/SQLite

## 📂 Project Files

| File | Description |
|------|-------------|
| `bank.py` | Main Python program |
| `bank_sqlite.py` | SQLite-based implementation |
| `bank.csv` | CSV data file |
| `bank.db` | SQLite database |
| `README.md` | Project documentation |

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the `Bank-System` folder.
4. Run the Python program.

```bash
python bank.py
